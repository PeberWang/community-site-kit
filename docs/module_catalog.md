# 模块目录与组合建议

| 模块 | 解决的问题 | 默认治理 | 适合何时启用 |
|---|---|---|---|
| 首页动态 | 新内容容易被错过 | 自动汇总已发布内容 | 有两个以上内容模块时 |
| 指南 | 经验散落、答案反复变化 | AI 候选 + 人工审核 + 版本历史 | 有需要长期维护的共同知识时 |
| 文章 | 完整表达被聊天切碎 | 投稿后审核 | 有稳定写作者时 |
| 活动 | 报名信息与回顾分散 | 发布前审核 | 社群有线上或线下活动时 |
| 广场 | 日常讨论缺少沉淀位置 | 先发后管 | 已有明确管理员和值守规则时 |
| 贡献 | 文件缺少使用语境 | 统一入口，审核后入库 | 需要收集资料或经验时 |
| 点赞留言 | 内容需要反馈和纠错 | 登录后互动 | 维护者能响应反馈时 |
| 审核后台 | 权限与发布责任不清 | 管理员操作留痕 | 任何正式上线站点 |

## 推荐组合

- 最小知识库：指南、贡献、审核。
- 内容社群：指南、文章、贡献、反馈、审核。
- 活跃组织：全部模块，但广场应最后开启。
- 展示型站点：指南、文章、活动，只读观察员；关闭公开注册。

模块是手段，不是成熟度勋章。每启用一个模块，都要同时确定负责人、审核方式、数据保留期和退出办法。
